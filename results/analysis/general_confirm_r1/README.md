# Confirmation analysis: general_confirm_r1

From the repository root, run `make confirmation` (no solver calls).

Each hash-named subdirectory contains 702 observations, 117 instances, 15 summary groups (ER separated by p), LaTeX tables, PDF/PNG figures, and source hashes. `paper/generated/general_confirm.tex` selects the version included in the PDF. Reruns check data and hashes and refuse to overwrite manually edited reports. Read the selected version's README for column definitions.

Older versions are retained for provenance and may preserve the original table language. Do not pool their CSVs as new benchmark samples. The source remains results/runs/general_confirm_r1.
