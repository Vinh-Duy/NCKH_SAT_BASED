# Historical CSVs predating pipeline standardization

Raw data are preserved. Complete metadata/witnesses are unavailable per file, so equivalence of timers, timeouts, symmetry, and source to the current pipeline is not established. Names such as cadical195, hybrid, or assignment are historical hints, not substitutes for manifests. Dictionary section 6 explains n,var,clause/constr,time,lambda,UB,status; section 4 explains symmetry schemas.

`conjectures_summary.txt` contains finite-data observations, not a collection of proved theorems. Current proofs are in docs/methods/theorems_and_proofs.md. A large incumbent is not a counterexample; new tests do not certify the 594 historical Petersen values. Do not discard data solely because newer code/results differ.

`bieu_do_lambda.png` is a historical figure. Without provenance, do not assign current-code sources or aggregation rules to it. A lambda axis label does not establish optimality.
