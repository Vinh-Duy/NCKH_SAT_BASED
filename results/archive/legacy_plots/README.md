# Cách đọc hình: legacy_plots

Hình lịch sử được giữ nguyên. Không phải đầu ra mới từ code hiện hành. Khi thiếu manifest liên kết chính xác ảnh–CSV–script, không suy nguồn hoặc cách gộp chỉ từ tên ảnh. Các hình *_comparison có thể dùng %; delta_* có thể dùng hiệu tuyệt đối: đọc nhãn trục và code lịch sử trước khi trích số, không áp định nghĩa hình mới hồi tố. C_6_labeling/bieu_do_lambda là hình minh họa hoặc kết quả cũ, không tự chứng minh công thức tổng quát.

[Giải thích dữ liệu nguồn](../legacy/README.md) · [Từ điển ký hiệu và biểu đồ](../../../docs/data_dictionary.md)

Các ảnh đang có được giữ nguyên trong đợt bổ sung tài liệu. README mô tả phạm vi sử dụng; không thay thế kiểm tra dữ liệu hoặc chứng thư tối ưu.
