Hình từ pilot cùng tên. Cactus đếm lượt OPT; runtime dùng cặp cùng OPT trong budget. File coverage.json/README.txt ghi điều kiện lọc. Pilot thiếu backend có thể chỉ có coverage mà không có hình; SKIPPED không phải TIMEOUT.
