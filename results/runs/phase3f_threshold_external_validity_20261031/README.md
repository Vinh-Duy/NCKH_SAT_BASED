# Phase 3F cross-graph threshold validity

Run with `.venv-1/bin/python -m experiments.phase3f_threshold_external_validity.runner`.
This isolated experiment uses eight original Appendix C graphs, `(h,k)=(3,2)`, one independently validated fixed U per graph, Reference/Threshold formulas, passive CaDiCaL195 statistics, and fresh sequential workers. It does not modify production or prior-phase artifacts, does not generate graphs, and does not use IPASIR-UP, GA, or ILP.
