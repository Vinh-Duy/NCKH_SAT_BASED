# Order-Encoded SAT Formulation

## 1. Problem Definition

Let $G=(V,E)$ be a graph and let $E_2$ denote the set of unordered vertex pairs at graph distance two. An $L(2,1)$-labeling is a function

$$
f: V \rightarrow \{0,1,\ldots,\lambda\}
$$

such that

$$
|f(u)-f(v)| \ge 2 \quad \forall (u,v)\in E,
$$

and

$$
|f(u)-f(v)| \ge 1 \quad \forall (u,v)\in E_2.
$$

The objective is to minimize the span $\lambda$.

## 2. Order Variables

For a fixed candidate span $s$, the model creates one Boolean variable $x_{v,i}$ for every vertex $v\in V$ and threshold $i\in\{0,\ldots,s-1\}$. Its semantics is

$$
x_{v,i}=1 \iff f(v)\le i.
$$

The value of a label can therefore be decoded from the first threshold variable that is true. If no threshold variable is true, the decoded label is $s$.

This representation uses $|V|s$ variables and avoids a separate one-hot variable for every possible label. Boundary thresholds are handled as constants: $f(v)\le i$ is always false for $i<0$ and always true for $i\ge s$.

## 3. Monotonicity

Order variables must be monotone. If a label is at most $i$, it is also at most $i+1$:

$$
x_{v,i}\Rightarrow x_{v,i+1}.
$$

The implication is encoded by the binary clause

$$
\lnot x_{v,i}\lor x_{v,i+1},
$$

for every $v\in V$ and $0\le i<s-1$. In the implementation, this is generated by `monotone_clauses`.

## 4. Excluding a Specific Label

The order encoding expresses the equality $f(v)=a$ as

$$
f(v)=a \iff (f(v)\le a)\land\lnot(f(v)\le a-1).
$$

Consequently, its negation is represented by the literals

$$
\lnot(f(v)=a) \equiv \lnot x_{v,a}\lor x_{v,a-1}.
$$

The boundary cases are simplified automatically when $a=0$ or $a=s$.

## 5. Forbidden Close Labels

For a pair $(u,v)$ with required minimum difference $d$, every assignment $(a,b)$ satisfying $|a-b|<d$ must be forbidden. The corresponding clause is

$$
\lnot(f(u)=a)\lor\lnot(f(v)=b).
$$

For graph edges, $d=2$; for distance-two pairs, $d=1$. The function `forbid_close_labels` enumerates these forbidden label pairs and converts each one into a CNF clause.

Together with monotonicity, this gives the exact feasibility test for a fixed span $s$. The SAT solver then determines whether the CNF is satisfiable.

## 6. Symmetry Breaking

Labeling problems contain interchangeable solutions. Adding sound symmetry constraints reduces the search space without changing satisfiability.

### Cycles $C_n$

For a cycle with at least three vertices, the implementation applies:

$$
f(0)=0,
$$

and fixes an orientation by imposing

$$
f(1)<f(n-1).
$$

The first condition removes translation symmetry in the labels. The second removes the two possible orientations of the cycle.

### Hypercubes $Q_d$

A $d$-dimensional hypercube has $2^d$ vertices after integer relabeling. The implementation fixes

$$
f(0)=0,
$$

and orders vertices associated with successive cube dimensions:

$$
f(2^{j-1})<f(2^j),
\qquad j=1,\ldots,d-1.
$$

These inequalities select one representative among equivalent coordinate permutations and label translations. They are generated only when the number of vertices is a valid power of two.

## 7. Search Interface

`build_cnf` combines monotonicity, symmetry breaking, edge constraints, and distance-two constraints for a candidate span. `src/solvers/sat_solver.py` repeatedly invokes this fixed-span model using either linear or hybrid span search. Every SAT model is decoded and independently checked by the shared validator before it is accepted.
