# Reading figures: products_main_r1_plots

Symmetry figures from the matching main_r1 run. delta_runtime and delta_clauses use Base−Sym: positive favors Sym, negative indicates an increase. The x-axis is vertex count; each point averages selected rows within a family/size. Runtime uses jointly OPT pairs only. Values are not percentages; rule none repeats the same model. Cartesian/corona overview figures retain separate family curves.
