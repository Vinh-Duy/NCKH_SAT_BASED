# Tables and figures used by the manuscript

These are derived artifacts; raw data are in results/runs. Do not edit numerical .tex entries to change results. Root main.tex includes paper/sections and these artifacts.

| Group | Meaning/source |
|---|---|
| tree_screen.tex, tree_screen_counts.tex | Audited 50-tree table/counts from tree_l32_screen_v2; tree_screen_sources.json records hashes and validation scope |
| timing.tex | Total configuration runtimes and median Base/Sym ratios on jointly OPT pairs, in seconds |
| counts.tex | Summary macros used in the text, not new solver observations |
| coverage.tex | Graph domains and OPT/unresolved pair counts |
| encoding.tex | Median variable/clause percentage reductions and fewer/equal/more counts on jointly OPT pairs |
| components.tex | Median CNF-construction/SAT-call seconds, B=Base and S=Sym; 0.0000 may reflect rounding |
| search_stats.tex | Total SAT conflicts and decisions across completed span trials, not variable/clause counts |
| run_config.tex | Recorded metadata configuration/environment |
| unresolved.tex | Unresolved pairs; incumbents are not established optima |
| sources.json | Main_r1 source CSV/metadata/witness hashes |
| *_main_r1_summary/ | Family summaries; twelve columns defined in the dictionary; source.json identifies inputs |
| *_main_r1_plots/ | Symmetry delta figures, Base−Sym; per-directory READMEs |
| manuscript_figures/ | Labeling/pipeline illustrations and tree plots; not all are benchmark measurements |
| general_confirm.tex | Pointer to the current versioned three-repetition confirmation report |
| english/ | English presentation copies of historical tables, with original/translated hashes; numerical entries unchanged |

See the [table/plot dictionary](../../docs/data_dictionary.md), [CSV catalog](../../docs/results_catalog.md). `make manuscript` audits the tree/confirmation inputs, generates figures, and compiles; it does not automatically certify arbitrary new CSVs. `make pdf` prepares English table copies and compiles existing data artifacts. The main_r1 exporter requires matching historical source hashes; do not edit manifests to bypass checks.

The pilot's original [summary.tex](../../results/analysis/general_pilot_v1/summary.tex) is preserved, while the English manuscript includes its translated presentation copy. The [audit README](../../results/analysis/general_pilot_v1/README.md) explains columns and theoretical bounds. English copies are generated by `scripts/export_english_tables.py`, which does not call solvers or modify original snapshots.
